AI WARDROBE ASSISTANT

A simple Python app that helps you pick your daily outfit from a folder of clothes pictures.

FEATURES

Welcome window with quick instructions.

Filter clothes by weather and style, or choose any.

Random selection if no picture matches your filter.

Clean design with a custom background image.
